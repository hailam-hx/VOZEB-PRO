# 社区参与与致谢

欢迎通过 GitHub Issue、Pull Request、文档补充、测试反馈或渠道适配样例参与 HOTX AI。提交前请删除 API Key、数据库密码、支付密钥、服务器私钥、Cookie、用户数据和未经脱敏的生产日志；安全漏洞请按<a href="/docs/support/security">安全与漏洞提交</a>私下反馈。

## 赞助支持

如果 HOTX AI 对你有帮助，欢迎通过[赞助支持页面](/docs/support/donate)支持项目维护、模型测试和文档迭代。

## 致谢

HOTX AI 基于原创开源项目持续开发。感谢原创开源作者 **basketikun** 对画布创作工作流、Canvas Agent 和 Codex 插件能力的开源贡献。

也感谢相关提示词开源仓库、Codex / Claude Code 生态，以及 React、Next.js、Ant Design、PostgreSQL、FFmpeg、Fumadocs 等项目使用的所有开源工具与基础设施。

## 参与项目

- 给 GitHub 仓库点 Star，帮助更多人看到项目。
- 使用脱敏信息提交可复现的 Issue。
- 补充文档、测试、模型渠道适配或小范围修复。
- 提交代码前阅读仓库根目录的 `CONTRIBUTING.md`、`AGENTS.md` 和 `CLA.md`。
